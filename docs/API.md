# API

Interactive docs: http://localhost:8000/docs (OpenAPI generated by FastAPI).

**Security model:** JWT bearer tokens (HS256, 12 h), bcrypt password hashes, Pydantic validation on every input,
project-scoped authorization (non-members get `404` so project existence is not leaked), role-based rules:
managers manage the project and members; assignees/creators edit their tasks; only managers or creators delete tasks.
CORS limited to configured origins. SQLAlchemy parameterised queries only.

| Method | Path | Purpose |
|---|---|---|
| POST | /api/auth/register · /api/auth/login | get a token |
| GET | /api/auth/me | current user |
| GET/POST | /api/projects | list (with health) / create |
| GET/PATCH/DELETE | /api/projects/{id} | project (PATCH/DELETE: manager) |
| GET/POST | /api/projects/{id}/members | team; add by email (manager) |
| PATCH/DELETE | /api/projects/{id}/members/{user_id} | role, capacity / remove (keeps ≥1 manager) |
| GET/POST | /api/projects/{id}/tasks | tasks with live risk / create (with dependencies) |
| GET/PATCH/DELETE | /api/tasks/{id} | task; PATCH logs status/assignee/deadline/estimate changes |
| POST/DELETE | /api/tasks/{id}/dependencies[/{dep}] | add (same project, no cycles) / remove |
| GET/POST | /api/tasks/{id}/updates | activity log / comment |
| GET | /api/projects/{id}/overview | dashboard bundle: health, workload, flow, risks, recommendations, model badge |
| GET | /api/projects/{id}/workload | per-member load with tasks |
| POST | /api/projects/{id}/what-if | simulate reassignment / deadline / estimate / status — **nothing saved** |
| GET | /api/tasks/{id}/risk | prediction, factors, features, history, blockers |
| POST | /api/projects/{id}/recommendations/{key}/feedback | applied / dismissed |
| GET | /api/projects/{id}/recommendations/stats | acceptance rate per recommendation kind |
| GET | /api/projects/{id}/health/history | health snapshots |
| POST | /api/projects/{id}/assistant | question → grounded answer (+ tools used, task ids, mode) |
| GET | /api/model | model card, metrics, thresholds, features |
