**Likely judge questions**
- *Is the data real?* Training: TAWOS (real). Demo project: synthetic, generated by the app, never used for training.
- *How do you avoid leakage?* Change-log reconstruction, snapshot-time features, chronological split (docs/ML.md §3).
- *Why not deep learning / GPT for predictions?* Tabular, 15 features, need calibration and explanations — gradient boosting / logistic regression are the right tools; the LLM only phrases answers from tool outputs.
- *How would you measure recommendation usefulness?* Acceptance rate per recommendation type (`/recommendations/stats`), and change in predicted risk after applied actions.
